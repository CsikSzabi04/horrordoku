# Saját portrék

A játék alapból a `src/content/looks.ts` alapján **rajzolt** portrékat használ. Ha egy karakterhez saját képed van (és jogod van használni), told ide
`<karakter-id>.png` (vagy `.jpg`, `.webp`, `.svg`) néven — pl. `ada-wong.png` —, és a játék azt mutatja a rajzolt helyett.
A karakter-azonosítók a `puzzles/event/*.json` fájlokban (`characters[].id`) vannak. Ajánlott méret: 5:6 arány (pl. 500×600 px), a kép közepén az arc.
